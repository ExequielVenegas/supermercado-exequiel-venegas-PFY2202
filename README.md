# Supermercado La Huerta

Actividad individual formativa de la semana 2 de Desarrollo Frontend II (PFY2202).

Aplicación React con React Router, estado global mediante Context y useState, y Tailwind CSS integrado con Vite.

## Ejecutar

```bash
npm install
npm run dev
```

## Funcionalidades

- Inicio con una bienvenida, contadores del inventario.
- Página Agregar artículo con nombre, marca, tipo, presentación, precio y stock.
- Página Inventario con resumen, tabla de artículos, búsqueda y filtros por categoría.
- Estado compartido entre páginas: los artículos agregados actualizan la tabla y el resumen.
- Validación de campos obligatorios y números enteros no negativos.
- Páginas Quiénes somos y Nuestras tiendas.
- Diseño adaptable con Tailwind CSS y estilos propios.

El inventario se mantiene durante la navegación. Al recargar se restablecen los productos de demostración; no se utiliza un servidor ni una base de datos.
